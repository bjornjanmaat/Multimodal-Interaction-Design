Key	Action
R	Start / Rematch Rock-Paper-Scissors Duel (Counts down from 5, determines winner)
H	Set Default Point (Activates Safety Box: Fwd/Bwd ±1m, Alt ±30cm, Lat ±50cm)
K	Clear Default Point (Disable Safety Box)
M	Enable / Disable Drone Physical Movement (Dry Run Mode)
Space	Emergency Stop / Pause Gesture Tracking Toggle
G	Toggle Gesture Recognition Tracking (On / Off)
I	Invert Forward / Backward Translation Direction
W / S	Move Forward / Backward (by forward step distance, default 40cm)
A / D	Move Left / Right (by lateral step distance, default 30cm)
U / J (or Up / Down)	Move Up / Down (by vertical step distance, default 10cm)
Q / E (or Left / Right)	Rotate Counter-Clockwise / Clockwise (30°)
T	Initiate Auto-Takeoff
L	Initiate Auto-Landing
C	Confirm Landing
P	Capture Photo
+ / -	Increase / Decrease step distance (+/- 5cm)
Esc or X	Quit Controller

Rock-Paper-Scissors Duel (Startup / Gatekeeper)
* Game starts in RPS mode: NO flight gestures are recognized until RPS is played!
* Press [R] on the keyboard to start the 5-second countdown (5, 4, 3, 2, 1, SHOOT!).
* Supports 2 Players (Player 1 vs Player 2) or Solo Mode (You vs Drone AI).
* Crowned winner gets exclusive drone flight gesture control.

Flight Gestures (Unlocked after winning RPS)
✊ Closing Hand	Move Forward by 40cm (speed depends on closing duration)
✋ Opening Hand	Move Backward by 40cm (speed depends on opening duration)
👍 Thumb Up	Climb / Move Up by 10cm
👎 Thumb Down	Descend / Move Down by 10cm
⚡ Averted Thumb	Trigger Wireless Haptic Motor Buzz
Neutral / None	Hover in place
